Como funciona

  • Valor do tributo = base de cálculo × alíquota efetiva, e a alíquota efetiva é a nominal menos a redução prevista na classificação tributária (cClassTrib). Ex.: CBS 8,8% com redução de 60% vira 3,52%.
  • A situação tributária (CST) e a classificação (cClassTrib) vêm das tabelas oficiais da data escolhida. A classificação diz se o item usa NCM (mercadoria) ou NBS (serviço).
  • Em 2026, ano de teste, as alíquotas são as de referência do período (CBS 0,9% e IBS 0,1%) e o motor não aceita outras. A partir de 2027 quem emite informa a alíquota nominal. Quando o motor marca um item como cálculo simulado, é ele avisando que aquela regra ainda não é definitiva.
  • Imposto Seletivo, NFS-e, base de cálculo unificada e geração de XML estão na API (abaixo); esta tela cobre o caso mais comum.

API grátis para sistemas e agentes

A mesma API da Receita, aberta, em /api. Documentação interativa: Swagger. Teto de 120 pedidos por minuto por IP.

Para agentes de IA: MCP em /mcp (ferramentas calcular_cbs_ibs, tabelas_cbs_ibs, aliquotas_referencia e versao_motor).

curl -X POST https://este-site/api/calculadora/observabilidade/regime-geral \
  -H 'Content-Type: application/json' -d @operacao.json
